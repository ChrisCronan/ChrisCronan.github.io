# ChrisCronan.com

Personal site for Chris Cronan. Plain HTML, CSS, and JavaScript, hosted on GitHub Pages.

## Local preview

```bash
python3 -m http.server 8080 --directory .
```

Then open http://127.0.0.1:8080/

The companion redirect site lives in `../chriscronan-cc-redirect/` and points every visit at https://chriscronan.com.

Fonts are self-hosted in `/fonts` (Roboto Slab, Source Sans 3, and Caveat; SIL OFL). The book interest form posts to Buttondown, and the contact form posts to Formspree. Mail can also go to chris@chriscronan.com.
